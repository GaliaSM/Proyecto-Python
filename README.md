# Proyecto-Python
En este proyecto encontrará las soluciones a los ejercicios Katas de Python plantedas en el Modulo de Python

# 🐍 PROYECTO LÓGICA: Katas de Python

Repositorio dedicado a la práctica, resolución y recopilación de ejercicios de programación en Python, abriendo desde conceptos básicos hasta lógica de decisión y algoritmos aplicados.

A lo largo de la solución de cada problema se aplicaron los conceptos fundamentales de programación, estructuras condicionales, estructuras de iteración, aplicación de funciones sobre tipos de datos iterables como son las listas, las tuplas y los diccionarios, para finalmente realizar programación orientada a objetos, definiendo las clases y aplicando los metodos desarrollados.

 ## ⚙️ Proceso de desarrollo
 
 En general, se procedio a resolver cada enunciado de forma independiente, determinando los requerimientos de entrada, proceso y salida. 
 Hubo varios problemas que planteaban desde el inicio las variables de entrada llenas, es decir no se pedian al usuario por teclado, como listas de números, o cadenas de caracteres, asi que se procedio directamente a trabajar sobre los valores que esas variables almacenaban. En otros casos fue necesario pedir por teclado al usuario para obtener los valores y hacer el programa mas dinámico.
 El proceso que se aplico depende mucho de lo que requerian hacer con los datos en cada kata por lo tanto hubo que aplicar la lógica de programación dependiendo de lo solicitado.
 Finalemete, se mostraba un resultado con la información que salia del proceso aplicado, obteniendo satisfactoriamente lo pedido en cada enunciado.
 
 En un principio se trabajo en un archivo con extensión .ipynb como se hacian a lo largo del módulo, el cual está entregado en el repositorio. Pero también se están entregando archivos .py por cada ejercicio como lo exigen en la documentación.
